# Données de démonstration

Le dossier contient le même dataset fictif NovaShop aux formats JSON et CSV.

NovaShop comprend :

- un projet ;
- trois sprints représentant un état sain, un état à risque et un état critique ;
- cinquante tickets ;
- des commits, Pull Requests, builds et résultats de tests liés ;
- des métriques de qualité ;
- neuf anomalies attendues utilisées par les tests.

La date de référence est figée afin de rendre les calculs de retard, de blocage et de fraîcheur
reproductibles. Les noms, identifiants et URLs ne correspondent à aucun projet, client ou dépôt
réel.
